# Dana-ODB

**Ontological Database for Dana Agents**

> Status: `design` — specs in progress, no implementation yet.

## Overview

Dana-ODB is the semantic knowledge layer for Dana agents — ontology-native, agent-queryable, reasoning-capable, and deployable from embedded single-agent packages up to large-scale distributed "minds."
